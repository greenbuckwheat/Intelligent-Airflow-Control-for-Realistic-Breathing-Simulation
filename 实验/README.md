# PWM exp：PPV 电气输出实验

本文件夹独立于原有 hardware GUI，原程序和固件未改动。此实验验证 **实际占空比 → PPV 输入端 DC 电压**，并导出目标电压到 PWM 的分段线性校准数据。它不测实际开度、完全夹闭或气动模型参数。

## 文件与运行

- `pwm exp.py`：PyQt5 可视化界面，输入 0–5 V 预期电压、直接设置占空比、升降序扫描、录入读数、绘图、导出 JSON/CSV、加载校准验证。
- `pwm exp/pwm_exp/pwm_exp.ino`：Arduino STM32 独立固件。sketch 文件夹与 ino 同名，便于 Arduino IDE 打开。

在终端运行：

```powershell
python -m pip install PyQt5 pyserial matplotlib
cd C:\Users\13922\Desktop\capstone\实验
python "pwm exp.py"
```

Arduino IDE 使用 STM32 MCU based boards，选择 Nucleo-64 / Nucleo G474RE。打开 `pwm exp/pwm_exp/pwm_exp.ino` 并上传。上传方法可选择 `OpenOCD STLink (SWD)` 或 `Mass Storage`；上传前关闭占用串口的 hardware GUI。本程序不要求连接流量传感器。

固件使用最终左支路连接：ATM D11、VAC D13、PPV PWM D5、低有效急停 D8。默认 MOSFET 驱动高有效。D5 必须经过已有滤波/3.3 V 转 5 V 电路；不是直接接 PPV 模拟输入。两路电磁阀在整个实验中保持关闭。保持 PPV 正常供电连接，不施加针筒负压；万用表 DC V 档，红表笔接 PPV 控制信号输入，黑表笔接信号地。

PWM 为 1000 Hz、12 位，匹配本机 STM32 core 2.12.0 的默认频率与原固件分辨率。若正式控制固件使用其他 core/频率，须重新确认频率一致。

## 操作步骤

1. 连接串口。UI 只接受 `PWM_EXP_G474` 专用握手，连接后先发送停止：ATM/VAC 关闭、PWM 100%（按原代码为名义 5 V / PPV 关闭）。
2. 点击“下一扫描点”。第一点为 0%，随后 10%、20%……100%，然后 100%、90%……0%。**0% 按原代码对应 PPV 全开，不是关闭。**
3. 等待固件 ACK 后至少 1 秒，确认万用表稳定，输入读数并保存该点。程序显示实际量化后的占空比，10% 等点可能略有舍入差异。扫描必须先保存当前点再继续。
4. 完成后选择 `up` 或 `down`，点击“检查并建立校准表”。程序报告相对原理想关系的最大误差、同点升降序最大差，并绘制实测曲线与理想直线。
5. 分别点击“保存校准 JSON”和“保存记录 CSV（可命名）”。两个保存窗口都可以自行选择目录和输入文件名。尚未建立校准表也可保存原始记录；加载 JSON 时会重新检查原始扫描数据的单调性。
6. 选择“实测校准表”，输入可达范围内的目标电压并发送。分别检查 0、1、2、3、4、5 V；不可达的端点会拒绝发送，不外推。录入实测电压后，表格显示 `实测 − 目标` 的误差。±0.05 V 可作为初步检查目标，结合万用表精度确定最终容差。
7. 完成后停止并断开；恢复原实验时重新上传原 `single_lung_controller_stm32.ino`。

“发送目标电压”的原理想模式使用 `PWM码值 = round(V目标 / 5 × 4095)`，用于验证原 hardware 换算。直接占空比模式与扫描绕过电压校准。校准模式对单方向、严格单调的实测数据反向插值；重复点、平台和非单调数据会拒绝建表。升降序原始数据分别保留，不自动平均。重置扫描只重置游标，重复实验建议保存后重新启动 UI，避免重复点混入同一张校准表。

## 如何判断实验结果

- 检查 `V实测 − 5 × PWM码值 / 4095`：它直接衡量原理想关系是否准确。仅仅曲线看起来直，不代表增益和零点准确。
- 升降序同点差异明显时，先检查稳定时间、电源、负载、温漂和测量重复性，再决定是否采用校准表。程序输出的是诊断数值，不自动宣称合格。
- 若最大值为 4.92 V，则 5 V 目标不可达；若最小值大于 0 V，则 0 V 也不可达。机械全开/全闭需要另外测试。
- DC 万用表验证稳态电平，不能证明 PWM 纹波或瞬态满足要求；必要时另测示波器波形。

## 停止、故障与协议

115200 baud、换行结尾。命令：`HELLO`、`PING`、`STOP`、`PWM,0` 至 `PWM,4095`。只有匹配的 ACK 后才能保存读数。UI 每约 0.7 秒发送心跳；固件活动输出失联超过 3 秒或急停触发后，关闭 ATM/VAC 并恢复 100% PWM。断开和正常关闭窗口也发送 STOP。

这里的“关闭 PPV”仅是原 hardware 的命令约定，尚未经机械验证。失联停止也不是断电。若实测电压超过 5 V，程序记录异常并发送 STOP；STOP 仍是 100% PWM，不能消除放大电路本身的过压，应停止实验并检查供电/电路。

## 校准文件与后续使用

JSON 保存通道、板卡、带时区日期、频率、分辨率、扫描方向、每点实际 PWM 码值/占空比/目标电压/实测电压/误差/时间、实测最低最高电压及校准点。CSV 保存所有测量记录。

本实验在自己的 UI 中验证校准换算，**不会让原 hardware 自动采用校准表**。原 hardware 的 PID 在 STM32 内运行，正式优化需将经过验证的校准表用于原固件的电压到 PWM 换算，并保留目标不可达的处理；本次按要求未修改原代码。通道、PWM 频率、滤波/放大电路或负载条件改变后重新检查校准。
