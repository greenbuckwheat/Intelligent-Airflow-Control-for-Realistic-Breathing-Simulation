# 2026-10-07 ATM / VAC figures

使用今天29份开环电压扫描数据，复用 today_hardware/screened_segments.csv 的筛选和累积体积拟合。并非闭环 hardware run 的瞬态波形。

ATM为正流量吸气；VAC为负流量呼气，负压源约40–45 kPa（用户提供，未实测压力）。两方向同一电压颜色一致。代表曲线选取该电压合格段中最接近时间常数中位数的单段，不是平均曲线；原始流量仅减去初始基线，不平滑、不延长未记录尾部。横轴零点为首次ON遥测，不是真实阀芯到位时间。波形显示前20秒，完整段时长见代表段清单。

筛选：ATM积分≥800 mL、末0.5 s流量≤1 SLM且时长≥3tau；VAC积分幅值≥800 mL，早期流量幅值中位数在4 V以下≥30 SLM、4–4.1 V≥8 SLM。此筛选不能证明阀门已完全打开。4.15 V泄漏/初态影响大，不用于拟合；4.2 V仅绘制实际记录的短时近零流量，不虚构无限长零流量或有限tau。

时间常数模型：tau=tau0/a_eff^gamma，a_eff=clip((Uc-U)/(Uc-Ud),0,1)，固定Uc=4.2 V，吸呼气独立拟合。参数依赖泄漏、初态和闭合电压假设，不代表纯PPV执行延迟。

PNG适合PPT，SVG为可缩放版本。representative_trials.json保留每条曲线的文件及段索引。
